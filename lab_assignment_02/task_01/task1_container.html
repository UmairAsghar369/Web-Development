📝 Answers

Q1: At what width does .container-sm become fixed-width?

.container-sm becomes fixed-width at the sm breakpoint (≥576px). Below 576px it is 100% wide. At 576px+ it snaps to 540px max-width.

Q2: Which container is best for a blog? For a dashboard? Why?

Blog → .container or .container-md — Blogs need readable line lengths. A fixed-width container centers content and prevents lines from being too long.

Dashboard → .container-fluid — Dashboards display lots of data (charts, tables) so using 100% screen width is important.
