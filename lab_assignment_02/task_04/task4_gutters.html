📝 Answer

Q: Why does Bootstrap use rem instead of px for gutters?

rem stands for "root em" and is relative to the root font size (usually 16px). Bootstrap uses rem instead of px because:

  • Accessibility: If a user increases their browser's default font size (for poor vision), rem-based spacing scales proportionally, keeping the layout comfortable. Pixels don't scale.
  • Consistency: All spacing stays proportional to text size, so the design feels harmonious at any zoom level.
  • Responsiveness: rem adapts better across different devices and user preferences than fixed pixel values.

Example: g-3 = 1rem = 16px by default, but if a user sets their browser font to 20px, then 1rem = 20px, and spacing grows accordingly.
