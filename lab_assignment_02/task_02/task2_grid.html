📝 Answers

Q1: How many columns appear side-by-side at each breakpoint?
  • xs (<576px): 1 column per row (each is col-12 = full width, stacked)
  • sm (≥576px): 2 columns per row (each is col-sm-6 = half)
  • md (≥768px): 3 columns per row (each is col-md-4 = one-third)
  • lg (≥992px): 4 columns per row (each is col-lg-3 = one-quarter)
  • xl (≥1200px): 6 columns per row (each is col-xl-2 = one-sixth)
  • xxl (≥1400px): 6 columns but each is col-xxl-1 = only 1/12 width
Q2: What happens when total columns in a row exceed 12?

When column units add up to more than 12, the extra columns wrap to the next line. For example, 3 columns of col-6 = 6+6+6 = 18 > 12, so the 3rd column drops below. This is called column wrapping and is how Bootstrap creates multi-row layouts from a single .row.
